[[📂 Sistem Informasi Inventory Dosir - PT TASPEN (Persero) Kantor Cabang Padang
📖 Deskripsi

Proyek ini merupakan hasil penelitian dan perancangan Sistem Informasi Inventory Dosir berbasis web yang dikembangkan untuk PT TASPEN (PERSERO) Kantor Cabang Padang.
Sistem ini bertujuan untuk mengatasi masalah pengelolaan dokumen kepegawaian (dosir) yang masih dilakukan secara manual, sehingga sering menimbulkan kesulitan dalam pencarian, peminjaman, pengembalian, serta monitoring status dokumen.

Dengan adanya sistem ini, proses pengelolaan arsip dosir menjadi lebih efisien, transparan, dan terstruktur, serta mendukung fitur notifikasi real-time terkait status peminjaman dan pengembalian dokumen.

🚀 Fitur Utama

Autentikasi & Hak Akses

Peminjam: Login, melihat daftar dosir, mengajukan peminjaman, mengembalikan dosir.

Admin: Login, kelola data user, kelola data dosir, verifikasi peminjaman & pengembalian, melihat & mencetak laporan.

Pimpinan: Melihat dan mencetak laporan peminjaman.

Manajemen Dosir

Penyimpanan data dosir (riwayat ASN: data pribadi, jabatan, pendidikan, pelatihan, penilaian kinerja).

Monitoring status dosir secara real-time.

Notifikasi

Informasi peminjaman dan pengembalian dosir.

Meningkatkan transparansi dalam proses pengelolaan dokumen.

Laporan

Data Peserta.

Data Dosir Peserta.

Data Manfaat.

Data Peminjaman Dosir.

Data Pengguna Sistem.
